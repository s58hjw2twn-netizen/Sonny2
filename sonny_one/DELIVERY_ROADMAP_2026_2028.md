# Sonny ONE — Delivery Roadmap
Version: 1.0 | 2026-10-24
Status: Planning targets, not verified completion dates or release commitments.

## Direction
Build an animated AI companion with independently operable inference, user-controlled memory, secure workflows, persistent self-modeling, and rigorously evaluated improvement. Follow LOW_TOUCH_DEVELOPMENT.md, INDEPENDENT_AI_POLICY.md, and FRONTIER_INTELLIGENCE_CHARTER.md. No claims of consciousness or universal competitive superiority.

## Milestones
1. Oct–Nov 2026 — Foundation: verify CI, implement provider-neutral inference contract with deterministic offline fallback and tests, security hardening, and begin mobile-responsive animated companion prototype.
2. Dec 2026–Jan 2027 — Memory/self-model: consent-based memory, versioned identity, capability prediction, calibration tests, natural voice prototype subject to licenses and cost.
3. Feb–Mar 2027 — Independent model: evaluate licensed open-weight model against reproducible benchmarks; document hardware, operating cost, latency, safety, and fallback.
4. Apr–Jun 2027 — Limited commercial beta candidate: user accounts, privacy/security reviews, iPhone browser/PWA tests, pilot metrics, and explicit release gates.
5. Jul 2027–Apr 2028 — Maturation and proprietary model research: licensed-data adaptation, controlled improvement experiments, competitor comparisons, independent validation.

## Planning windows
Animated interactive prototype: 4–8 weeks.
Independently powered model demo: 3–5 months.
Limited commercial beta candidate: 6–9 months.
More mature independent AI product: 12–18 months.
Original frontier-class foundation model or genuine consciousness: no credible promised deadline.

## Delivery gates
Each milestone requires recorded commit SHA, exact commands and test results, security review, cost/license review, known limitations, and a concrete next action. Dates move if quality gates fail. No merging, public deployment, App Store submission, paid services, secret access, frozen research changes, or consequential external actions without owner approval.

## Immediate execution queue
A. Inspect research/apl-001 HEAD, CI, existing inference entrypoints and tests.
B. Implement the smallest provider-neutral inference adapter with offline deterministic tests; run targeted and full available suites.
C. Review security and preserve regression evidence; commit a grouped, verified change.
D. Prototype animated responsive Sonny on a separate authorized research feature path or within research branch, without affecting production.
E. Begin self-model prediction and calibration instrumentation.

## Resource policy
Prefer local free tools and existing CI; batch work; minimize remote calls. No implied unattended development outside an active execution session.
