# Sonny ONE — Research Foundation 0.1

Experimental branch only. No production integration or changes to frozen research artifacts.

Modules: stable versioned identity, explicitly simulated emotional variables, consent-gated per-user SQLite memory, and bounded RSI proposal review. These are prototypes, not evidence of sentience, continuous self-improvement, or model-weight modification.

Run: `python -m pytest tests/test_sonny_one.py` (requires pytest).

Security limitations: local prototype storage is unencrypted, no authentication or deployment controls, no retention scheduler, and no external independent evaluation yet. Do not store sensitive real user data or expose as a service. Passing unit tests does not establish production readiness.
